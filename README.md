## Build

```sh
cargo build --release      # -> target/release/pdfid
cargo test
```

## Usage

```
pdfid [OPTIONS] <FILE|DIR|->...

  -a, --all       Print all names
  -e, --extra     %%EOF, dates, entropy
  -n, --nozero    Hide keywords with a count of 0
  -d, --disarm    Write <name>.disarmed.<ext> (active names case-swapped)
  -f, --force     Scan even without a %PDF header
  -s, --scan      Scan directories recursively
      --json      JSON output
      --triage    Exit code 2 on suspicious keywords
```

Exit codes: `0` ok, `1` error (takes precedence), `2` suspicious (only with `--triage`).

## Compatibility

Tokenizer, header detection (relaxed, the header line is not tokenized), `#xx` deobfuscation,
the `%%EOF` and date state machine, entropy attribution (including subtracting `endstream`),
and the disarm set are replicated 1:1. Text output is byte-identical to the original (except for the
first line `PDFiD-rs <version> <file>`).

Intentional deviations:

- The original crashes, the port does not: empty file with `-f -e` (ZeroDivisionError), header at the end of the file
  or at the end of the 1024-byte window, e.g. `%PDF-1` (IndexError).
- Disarm only changes the affected names; the original additionally rewrites all `#xx` escapes
  to lowercase. File size and xref offsets stay the same in both cases.
- Not carried over: plugins (`-p`), additional keywords from `pdfid.ini`, XML output, ZIP/URL input.
- New: `--json`, `--triage`.

## Tests

```sh
cargo test                                   # Unit, CLI and golden tests
python3 -I tests/parity.py --orig /path/to/pdfid.py tests/fixtures ~/pdf-collection
```

| Level | Location | Content |
|---|---|---|
| Unit | `src/lib.rs` | Tokenizer, hex escapes, `/Colors` boundaries, header/`repr`, `%%EOF` and date state machine, entropy, disarm |
| Golden | `tests/golden.rs` | 20 fixtures × 6 flag combinations + disarm, reference output from the original |
| CLI | `tests/cli.rs` | Arguments, stdin, `-s`, JSON, `--triage` exit codes, disarm files, error cases |
| Parity | `tests/parity.py` | Differential comparison against pdfid.py on arbitrary files |

The original has no tests or test data of its own. The fixtures and golden files are generated by
`tests/gen_fixtures.py` using the original (only needed when fixtures change):

```sh
python3 -I tests/gen_fixtures.py /path/to/pdfid.py
```
